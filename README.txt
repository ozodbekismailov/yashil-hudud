# Yashil Hudud — ekologik muammolarni xaritalash platformasi

## Ishga tushirish
1. ZIP arxivni kompyuteringizga oching.
2. `index.html` faylini Chrome yoki Edge brauzerida oching.
3. Xarita va shriftlar uchun internet aloqasi kerak.
4. Chap menyu orqali Bosh sahifa, Xarita, Ariza yuborish va Admin paneli bo‘limlarini sinab ko‘ring.

## Funksiyalar
- Leaflet va OpenStreetMap asosidagi interaktiv xarita
- Xarita ustiga bosib koordinata tanlash
- Muammo turi, manzil, tavsif va ixtiyoriy rasm bilan ariza yuborish
- Holatni boshqarish: Yangi / Ko‘rib chiqilmoqda / Bajarildi
- Statistika va muammo turlari diagrammasi
- Qidiruv va filtrlar
- CSV eksport
- Brauzer localStorage xotirasida saqlash

## Muhim cheklovlar
Bu o‘quv prototipi. Ma’lumotlar faqat joriy brauzer va qurilmada saqlanadi. Admin paneli haqiqiy autentifikatsiya bilan himoyalanmagan. Haqiqiy foydalanish uchun backend API, ma’lumotlar bazasi, login/rol tizimi, serverda fayl saqlash, spamdan himoya va maxfiylik siyosati kerak bo‘ladi.
